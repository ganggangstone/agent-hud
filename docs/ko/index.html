플러그인 & 스킬 탭. 숫자는 사이드바에서 고른 프로젝트 기준입니다.

프로젝트마다 쓰는 스킬과 플러그인이 다른데, 다 로드하면 비용과 성능에 부담이 되고 매번 켜고 끄기도 번거롭습니다.

코딩 에이전트는 세션을 시작할 때 설치된 스킬마다 이름과 설명을 모델 입력에 넣습니다. 본문은 실제로 쓸 때만 읽지만, 이름과 설명은 그 세션에서 한 번도 안 쓰는 스킬까지 전부 들어갑니다.

플러그인을 끄는 기본 명령은 사용자 전역 설정 파일에 기록합니다. 여기서 끄면 모든 프로젝트에서 꺼집니다.

쓰든 안 쓰든 설치된 스킬은 전부 올라갑니다

한 대의 컴퓨터, 플러그인 3개. 특별히 많이 깔아둔 상태는 아닙니다.

설치된 스킬60개
그 스킬들의 이름과 설명을 합친 글자 수18,938자
세션마다 거기 쓰이는 토큰5,000~9,000

Agent Skills 명세는 스킬 하나의 metadata를 약 100토큰으로 봅니다. 실제 값은 설명 길이에 따라 다르므로, 대시보드는 남의 컴퓨터 숫자 대신 지금 열어둔 프로젝트의 숫자를 보여줍니다.

그룹

켜고 끄는 단위가 그룹입니다. 적용하면 그 그룹의 스킬이 프로젝트 스킬 폴더에 링크되고, 그룹의 플러그인은 켜지고 나머지는 꺼집니다. 그 내용은 프로젝트의 .claude/settings.local.json에 적히고, 다른 프로젝트는 바뀌지 않습니다.

세션이 끝나도 남습니다. 플러그인 변경은 다음 세션부터 반영됩니다.

  1. 그룹을 만들고 플러그인과 스킬을 담습니다.
  2. 사이드바에서 프로젝트를 고릅니다.
  3. 적용합니다. 폴더에서 agent-hud apply dev로도 됩니다.

modes.json

{
  "dev": {
    "plugins": ["mattpocock-skills@mattpocock"],
    "skills": ["diagnosing-bugs"]
  },
  "video": ["video-tools@local"]
}

그룹 탭에서 고쳐도 되고 파일을 직접 고쳐도 됩니다.

대시보드의 나머지 화면

스킬 폴더 하나, 에이전트 여섯 개

심볼릭 링크

스킬 형식은 공개 표준입니다. 에이전트마다 읽는 경로가 달라서, 대시보드가 스킬 하나를 두 폴더에 심볼릭 링크로 겁니다.

덤이고, 만든 이유는 위쪽에 있습니다.

설치

git clone https://github.com/ganggangstone/agent-hud.git
cd agent-hud && ./install.sh

또는 brew install ganggangstone/tap/agent-hud

브라우저가 127.0.0.1:7717에 열리고 launchd 서비스가 계속 띄워둡니다. 이 부분은 macOS 전용이고, Linux는 systemd --user 유닛이 server.py를 실행하게 하면 됩니다. Windows는 아직 지원하지 않습니다(#1).
