Plugins & skills tab. The count at the top is for the project selected in the sidebar.

Different projects use different skills and plugins. Loading all of them costs tokens and slows things down, and switching them by hand every time is a chore. why this was built

A coding agent puts the name and description of every installed skill into the model's input when a session starts. It needs that list to pick a skill mid-conversation. A skill's body is only read when the skill is used, but the names and descriptions all go in, including the ones that session never touches.

And the usual way to turn a plugin off writes to the user-wide settings file. Turn it off for this project and it is off in every project, so you turn it back on the next time you switch.

What that came to on one machine

“Nothing unusual, no deliberate hoarding.”

Three plugins were installed.

load line

Everything above the line is installed and idle. Everything below it is riding in the context this session.

The Agent Skills specification puts one skill's metadata at about 100 tokens. Your own figure depends on how long your installed skills' descriptions run, which is why the dashboard shows the count for the project you have open rather than a number from someone else's machine.

A group is the unit that was missing

“Other projects are left alone.”

scope

Applying a group writes inside one project. The other keeps what it had.

Name the plugins and skills you use together. Applying a group links its skills into that project's skill folders, turns the group's plugins on and the rest off, and writes it into that project's .claude/settings.local.json.

The setting survives the session, so the next one starts the way you left it. Plugin changes take effect from the next session.

  1. Create a group, add plugins and skills.
  2. Pick the project in the sidebar.
  3. Apply. Or run agent-hud apply dev from the folder.

modes.json

{
  "dev": {
    "plugins": ["mattpocock-skills@mattpocock"],
    "skills": ["diagnosing-bugs"]
  },
  "video": ["video-tools@local"]
}

Edit it in the Groups tab or in the file. The dashboard picks up file edits on its next refresh.

Two more tabs

One folder, two links, six agents

“A folder moves as it is.”

symlink

The skill format is an open standard. Each agent reads a different path, so the dashboard symlinks one skill into both project skill folders. Two links cover six agents. Cursor and Copilot read both folders.

This is a side benefit, not the reason the tool exists. Instruction files stay per agent, and the dashboard only lists them.

Install

git clone https://github.com/ganggangstone/agent-hud.git
cd agent-hud && ./install.sh

or brew install ganggangstone/tap/agent-hud

A browser opens at 127.0.0.1:7717 and a launchd service keeps it running. macOS only for that part; on Linux point a systemd --user unit at server.py. Windows is not supported yet (#1).
