Every installed skill loads, whether you use it or not

A coding agent puts every installed skill's name and description into the model's context at session start. The body only gets read when you actually use that skill — but the name and description go in regardless, for skills you never touch in that session.

The default way to turn a plugin off writes to your user-wide settings. Turn it off in one project and it's off everywhere.

Three tabs

Groups

Applying a group links its skills into the project's skill folder and writes the plugin values into that project's settings file. Other projects are untouched. Plugin changes take effect next session.

agent-hud apply backend
agent-hud groups

Other agents

The skill format is a public standard, so a folder moves as-is. One checkbox links the same skill into six agents' skill folders. Cursor is not yet verified by hand.

Agent instructions

Finds 30 kinds of instruction files across the project tree and shows size and last-modified time. It does not diff their contents — it's an index, not a drift detector; the comparing is left to you.

git clone https://github.com/ganggangstone/agent-hud.git
cd agent-hud && ./install.sh

or brew install ganggangstone/tap/agent-hud

A browser opens at 127.0.0.1:7717. macOS only — Linux works as a systemd --user unit, Windows isn't supported yet (#1).

No account needed. It only reads and writes files on this computer. The only request that leaves it is a GitHub Releases check for a new version.
