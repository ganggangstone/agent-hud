# 랜딩 페이지

`docs/index.html`(영어)과 `docs/ko/index.html`(한국어). GitHub Pages가 `main`의 `docs/`를
그대로 서빙한다. 빌드 단계는 없다.

- 영어 https://ganggangstone.github.io/agent-hud/
- 한국어 https://ganggangstone.github.io/agent-hud/ko/

## 고칠 때 지킬 것

**색 변수는 `server.py`의 `:root`를 그대로 복사한다.** 랜딩 CSS 맨 위에 출처 주석이 있다.
제품과 페이지의 색이 갈라지면 같은 제품으로 안 보인다. 색을 바꿀 일이 생기면 `server.py`를
먼저 고치고 두 페이지로 옮긴다.

**두 언어를 한 페이지에 넣지 않는다.** 토글로 스왑하면 구글이 그 페이지의 언어를 판단하기
애매해져 검색 노출이 떨어진다. 파일을 나누고 `hreflang` alternate로 서로 연결한다
(`x-default`는 영어). 정적 파일 하나 더 두는 정도라 빌드 없음 원칙에서 벗어나지 않는다.

**스크린샷은 전부 가짜 데이터로 찍는다.** 실제 경로·프로젝트명·플러그인명이 들어가면 안 된다
(`sanitized-demo-screenshots` 스킬). 이미지에 `width`/`height` 속성을 넣되 CSS에 `height:auto`를
같이 둔다. 안 그러면 좁은 화면에서 가로만 줄고 세로가 고정돼 찌그러진다.

**문장은 읽는 사람이 묻는 것만 쓴다.** 전역 `CLAUDE.md`의 글쓰기 원칙(31번)을 따른다.

## 기록

2026-09-22~23에 카피와 구조를 네 번 갈아엎었다. 마지막에 개발자·바이브코더·비개발자
세 페르소나에게 문장 단위로 읽혔더니, 둘이 흥미가 아니라 **불안 때문에** 설치 직전에 멈췄다
— 되돌리는 방법과 전역 설정을 건드리는지가 페이지에 없어서였다. 기능은 이미 있었는데
적어두지 않아 잃고 있었다. 그 뒤로 FAQ에 "되돌리거나 지우려면요?"가 들어갔다.

SEO 메타데이터(OG·트위터카드·JSON-LD·`sitemap.xml`·`llms.txt`)는 2026-09-23에 넣었다.
`docs/robots.txt`는 두긴 했지만 크롤러가 도메인 루트만 보므로 프로젝트 페이지에서는 읽히지
않는다. 사이트맵은 Search Console에 직접 제출해야 한다.
